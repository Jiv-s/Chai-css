ChaiCSS

This project focuses on DOM manipulation, pattern parsing, and building a reusable client-side library that mimics the behavior of utility-first CSS frameworks.

Supported Utilities

  • Spacing: chai-p-# (padding), chai-m-# (margin), chai-pt, chai-pb, chai-pl, chai-pr, chai-mt, chai-mb
  • Colors: chai-bg-[color], chai-text-[color]
  • Typography: chai-fs-# (font-size)
  • Borders: chai-radius-# (border-radius)
  • Sizing: chai-w-# (width), chai-h-# (height)
  • Alignment: chai-align-[left|center|right]
  • Layout: chai-flex, chai-center, chai-flex-wrap
  • Gap: chai-gap
